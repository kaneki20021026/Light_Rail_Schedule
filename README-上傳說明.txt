# 更新版：兆麟 → 屯門

將 ZIP 解壓後，把全部檔案放進 GitHub Pages 網站的同一資料夾，取代原有版本，不要只上傳 index.html。

## 新增 751 接駁建議

頁面同時讀取兆麟站及安定站的港鐵即時到站資料。計算 614／614P 到安定約 2 分鐘後能否接上安定站下一班 751；若接得上，並估算比兆麟下一班 505 和 507 更早抵達屯門，才顯示接駁建議。估算安定至屯門約 4 分鐘。若班次已開出、資料缺漏或接駁不會更快，就不顯示 751。

## iPhone 主畫面圖示

GitHub Pages 更新後，以 Safari 重新開啟網站，移除原來的主畫面捷徑，再按「分享」→「加入主畫面」，即可載入新輕鐵圖示。

本頁每 15 秒讀取港鐵資料，需保持連網。圖示檔和 manifest 必須與 index.html 放在同一資料夾。
