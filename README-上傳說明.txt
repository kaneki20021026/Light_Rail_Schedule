# 更新版：兆麟 → 屯門

## 上傳 GitHub Pages

將以下 6 個檔案放在同一個資料夾，取代原本網站的 index.html。請上傳解壓後的檔案，不要只上傳 ZIP：

- index.html
- apple-touch-icon.png
- icon.svg
- icon-192.png
- icon-512.png
- manifest.webmanifest

全部使用相對路徑，可用於 GitHub Pages 的儲存庫子路徑。無須安裝或建置。

## 更新 iPhone 主畫面圖示

1. 等候 GitHub Pages 完成更新。
2. 用 Safari 開啟網站並重新整理，確認已是精簡版介面。
3. 移除原本主畫面上顯示「兆」的舊網頁圖示。
4. 在 Safari 按「分享」→「加入主畫面」。如有「以網頁 App 開啟」選項，保持開啟。
5. 新增時應顯示深綠色輕鐵圖示。iOS 可能快取舊圖示；若仍顯示舊圖，先在 Safari 的網址後加上 ?v=2 再重新加入。
