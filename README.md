# 下一班車

原有兆麟往屯門的 505 / 507 輕鐵預報，加上：
- 屯門往烏溪沙：屯馬綫 TML / TUM，DOWN 方向，只顯示 WKS。
- 調景嶺往寶琳：將軍澳綫 TKL / TIK，UP 方向，只顯示 POA，排除康城 LHP。

將整個資料夾內容放到原本的靜態網站目錄；index.html 與 rail.js 必須一同更新。毋須建置或 API 金鑰。以 HTTPS 網站提供服務。

三段班次每 15 秒自動更新。新增港鐵班次顯示月台、預計時刻、倒數和延誤提示；超過 90 秒的資料會被隱藏。港鐵每方向最多回傳四班，所以排除康城後可能少於四班，亦可能暫無寶琳班次。

定位功能尚未加入。

驗證：JavaScript 語法檢查、9 項資料篩選測試通過；已查核調景嶺實際 API 回應；屯門實際請求因 DNS 失敗未能驗證。受本機預覽權限及瀏覽器 file URL 限制，未完成瀏覽器視覺驗證。

## 分頁介面

App 圖標及名稱下一行的三個精簡列車圖標按鈕切換輕鐵、屯馬綫及將軍澳綫，每次只顯示一頁。按鈕以 40px 高度橫排圖標和路線名稱，起訖站名顯示於各分頁標題，並用綠／啡／紫色區分。支援鍵盤左右方向鍵、Home、End；各頁有獨立更新按鈕。部署時請一併上傳 tabs.js。
