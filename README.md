## GPS 與剩餘站數

在兩個港鐵分頁的下一班車卡片下顯示目的地、剩餘站數和小型路線圖標。屯馬綫下車目的地為鑽石山（屯門起計 16 站），將軍澳綫為寶琳（調景嶺起計 3 站）；不改變到站 API 的出發站及列車目的地篩選。

按定位按鈕才啟動瀏覽器 watchPosition，須 HTTPS（本機開發 localhost 亦可）和使用者授權。使用高精度請求、10 秒位置快取、15 秒逾時。再次按下關閉；背景暫停，返回前景恢復。定位只存在記憶體，本頁不把座標上傳或持久儲存。

計算以官方站序相減：不計目前站、計目的地。GPS 比對各站出入口及其平均位置，以球面距離找最近站。座標須在 60 秒內、精度不差於 150 米、距離車站不超過 250 米；最近兩站的距離差須大於兩倍定位誤差加 50 米。門檻是可調整的工程設定，尚未經實地校準。

GPS 只推估附近車站，不確認乘客已在車上。顯示「約 N 站」及「附近：站名」。兩站之間、地下失訊、定位不準、權限拒絕及遠離路線時顯示 —；不根據經過時間自動扣站。到達目的地附近顯示約 0 站；越過鑽石山顯示已越過目的地；康城屬支線，不能直接套用往寶琳站序。可使用小型選單手動指定目前站（顯示「手動」且不加「約」）。輕鐵頁本次未加入 GPS 站數。

## 分頁介面

App 圖標及名稱下一行的三個精簡列車圖標按鈕切換輕鐵、屯馬綫及將軍澳綫，每次只顯示一頁。按鈕以 40px 高度橫排圖標和路線名稱，起訖站名顯示於各分頁標題，並用綠／啡／紫色區分。支援鍵盤左右方向鍵、Home、End；各頁有獨立更新按鈕。部署時請一併上傳 tabs.js。
